# 📊 Employee Salary Analysis — SQL Practice Set

## 📌 Overview
This project is a SQL practice set created using an Employee dataset.  
It contains multiple SQL business problem questions and solutions designed for practicing SQL concepts used in Data Analytics and Business Analysis.

The practice set focuses on solving real-world employee salary and department analysis problems using SQL queries.

---

# 🛠️ Tech Stack
- SQL
- MySQL

---

# 📂 Dataset Information

## Employees Table

| Column Name | Description |
|---|---|
| emp_id | Employee ID |
| emp_name | Employee Name |
| department | Department Name |
| salary | Employee Salary |
| city | Employee City |
